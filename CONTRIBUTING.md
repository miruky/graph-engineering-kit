# Contributing

Keep target-project languages unrestricted. Add a regression case for a behavior change, then run `python3 kit.py check` and `python3 kit.py demo`. Preserve existing user configuration and fail explicitly on unsupported inputs. Do not add an implicit provider call, an approval bypass flag, unpinned runtime download, or credential value.

Document the actual contract and its limits. Keep private work reports, local paths, model conversations and generated state out of the repository. Example/test data must be synthetic. Do not claim an unperformed live integration or equate a provider invocation with product verification.
